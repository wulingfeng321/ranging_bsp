# 测距检测宽松调试参数

为两板 READY 但完整签名漏检的问题启用 `APP_RANGE_RELAXED_DETECTION=1`。
两板均须重新编译烧录，除 A/B 角色外保持配置一致。

- 三段最低相关系数从 0.45 调整到 0.30；UDP EVENT 最低质量同步从 450 调整到 300。
- 去直流后的最低 PCM RMS 从 64 调整到 32。
- 两段间隙能量上限从第一段能量的 0.6 倍调整到 1.0 倍。
- 粗搜平方相关门槛仍为 0.08，避免提前选择旁峰。仍要求完整 Up–Down–Up 签名。
- 仍使用 L 通道、同步锁定、同事件时间配对和原距离范围。宽松参数不能解决音频丢弃、事件传输或时间戳异常。

在 `Core/Inc/app_board_config.h` 将开关设为 0 可恢复原检测参数，网络门槛随之恢复。
此配置用于上板调试，可能增加误检和反射声触发；出现距离不代表精度已验证。

验证：主机 DSP 测试覆盖真实 WAV 定位、弱信号、静音/噪声/单音/错误签名拒绝；
A/B 状态机测试覆盖配对与网络质量门槛。未进行本次 IAR 构建或硬件测距验证。
