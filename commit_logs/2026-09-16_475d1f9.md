## 整理后的提交说明

加入 `tools/sound_make.py` 及 `tools/test_audio_chirp.wav`，为后续声学测距准备重复扫频测试音。

脚本依赖 NumPy、SciPy、SoundFile，其参数如下：

| 项目 | 脚本设置 |
| --- | --- |
| 输出 | 16 kHz、16-bit PCM、单声道 |
| 单段 chirp | 32 ms / 512 点，线性扫频 |
| 上扫 / 下扫 | 2→6 kHz / 6→2 kHz |
| 相位与幅度 | SciPy chirp 默认 phi=0；量化前乘 32767×0.9 |
| 渐变包络 | np.hanning(32) 的前/后各 16 点；段中保持 1 |
| 单个签名 | Up 32 ms + 静音 8 ms + Down 32 ms + 静音 8 ms + Up 32 ms |
| 签名长度 | 112 ms / 1792 点 |
| 签名周期 | 500 ms / 8000 点，签名后静音 388 ms |
| 重复次数 | 5 次，起点 0、500、1000、1500、2000 ms |
| 完整输出 | 2.5 s / 40000 点，含最后一段尾部静音 |

代码对签名长度与周期样点数执行断言。完整文件最后一段声音结束于 2112 ms，尾部仍保留静音至 2500 ms。

## 使用与边界

脚本以相对输出名写入当前工作目录；在 tools 目录运行才会输出到 tools/test_audio_chirp.wav。以上参数依据已提交脚本，未在本次整理中重新生成音频或做扬声器播放验证。

本提交仅增加离线测试音素材，不修改固件，不实现板上播放、匹配模板导出或声音事件检测。未来模板必须遵循脚本的实际离散包络和相位定义，不能换成整段 Hann 窗后仍视为同一模板。
