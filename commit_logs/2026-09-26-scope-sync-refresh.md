# 48 kHz：低频整帧波形与固定诊断

## 改动

- 150 ms 刷新改为 500 ms（2 Hz）；取消覆盖扫描、亮暗游标和候选音触发冻结。
- 保留最近 160 ms 的双通道窗口、共同幅度缩放和每列极值。复制环形缓冲时从最旧样点开始；
  不屏蔽 DMA 中断，复制期间若 DMA 写入则重试。移除 10,240 字节的旧冻结缓冲。
- `AppRange_MasterTime()` 仅在时钟已初始化、网络在线且同步锁定时返回 A 时钟域时间。
  B 使用已有的偏移/频率修正模型；显示不修改同步模型及 D9 PPS。
- 在共同的 500 ms 边界前 100 ms 准备隐藏帧，到边界请求垂直消隐切换。
  绘图仍受 DSP 积压门限限制，已完成帧的切换不受该门限限制。
  忙时跳过未能准备的帧，主循环停顿超过一周期时丢弃过期帧，不突发补刷。
- 未锁定时保留低频状态/诊断显示，丢锁时撤下波形并丢弃尚未提交的帧。
- L/R 各留三行固定文字，取消两秒轮换；增加采样周期、采样率、同步误差、音频时间拒绝计数。
  顶部结果状态统一使用 Font12，避免 `LAST / PEAK UNCERTAIN` 超出右侧区域。

## 验证

- `tools/build_range_profiles.ps1 -Profiles legacy -JointPeaks`：48 kHz A/B 均零错误、零警告。
- `tools/tests/run_scope_tests.ps1`：实际显示 C 代码在主机上通过 A/B 时钟节拍、
  准备/提交分离、DSP 忙、垂直消隐待决、丢锁/重锁、过期帧丢弃、环形窗口排序测试。
- 主机测试调用实际显示代码与 ST 字库生成 480×272 预览，并检查文本、线段边界及所有诊断行同时存在。
  预览位于 `%TEMP%/ranging-host-tests/scope1.ppm`、`scope2.ppm`，属于模拟数据，不是开发板实拍。
- 实际 `AppRange_MasterTime()` 的 A/B 偏移、斜率映射，以及离线、丢锁、时钟未初始化均已测试。
- 已使用 IAR CSpyBat 分别烧录，启用 `--drv_verify_download` 并请求烧录后运行；两次退出码均为 0。
  A 固件对应 ST-LINK `0675FF514966504867230834`（短号 `67230834`），
  B 固件对应 `0667FF485153826687134138`（短号 `87134138`）。未通过相机直接确认屏幕状态。

## 上板观察

1. 两板均显示 `JOINT2 48k`；等待 `SYNC READY` 后开始显示波形。
2. 应每半秒整帧切换，全部参数一直显示，无扫描和轮换。
3. 播放 10.5 s + 5 s 的 48 kHz 测试音，记录两侧距离、`PK/AM/IC/DS`、`DSP/MAX/BK`、`D/G/O`。
4. 观察 LCD 是否大致同时切换；精确时钟同步仍由 D9 PPS 检验。

显示窗口只覆盖每 500 ms 中的一段 160 ms，不能保证每个短签名都出现在波形图中；
音频 DMA 和测距处理保持连续。两板各自的 DMA 块边界、主循环延迟及 LCD 垂直刷新独立，
共同刷新节拍不保证两张图的采样端点完全一致，也不保证微秒级 LCD 同步。
实际负载改善和两板屏幕效果仍需用户上板观察。
