# 波形更新改为覆盖扫描

- 日期：2026-09-17
- 编写：Codex 协助实现，实际提交作者以 Git 记录为准。
- 开发基线：50c5c4c 及工作区 README/日志改动。
- 状态：已实现；后续去除扫描线并加入触发保持的整合版本，已于 2026-09-17 获开发者上板确认，详见 waveform-trigger-hold 日志。本文保留覆盖扫描初版的设计记录。

## 目的与修改

将最新 160 ms 样点按时间排序滚动显示，改为固定横坐标的循环覆盖显示。

- 修改 Core/Src/app_mic_scope.c：覆盖缓冲为 2560 帧，DMA 回调写到末尾后回到开头，使用显式边界判断，不能对非二次幂长度使用位掩码取模。
- 主循环按缓冲物理位置复制快照，不再旋转样点顺序；快照和扫描位置在同一短临界区读取，L/R 共用扫描位置。
- 黄色竖线标记下一写入位置，前方 4 像素不画波形，区分扫描接缝；本轮为亮绿/亮青，上轮未覆盖部分为暗绿/暗青。
- 保留 16 kHz、16-bit 双通道、160 ms 时间跨度、40 ms 目标刷新间隔、每列极值、双显示缓冲和测距 UI。
- README 同步更新显示行为与缓冲区说明。

## 接口与兼容性

无对外接口变化，距离状态和发布接口保持不变。横坐标固定，但共同自动幅度缩放仍会调整纵向比例。扫描位置两侧来自相邻两轮，不应将整幅图当作从左到右连续的同一时间段。首次仍等待一屏采样后显示。

## 验证

- 主机模型模拟 35 个 DMA 半缓冲，包含三次完整回绕，检查未写入槽位不移动、游标始终位于 0..479，通过。该检查针对索引规则，不替代真实固件执行。
- 使用 IAR Embedded Workbench 8.2 安装目录中的 IarBuild 构建 ranging_bsp 配置，全量编译与链接通过：0 错误、0 警告。未执行烧录或硬件验证。
- 上板验收：播放测试音，确认旧波形不水平滑动，黄色游标从左向右并回绕，两路游标一致；距离信息区正常刷新。

## 限制

160 ms 扫描一屏较快，40 ms 刷新下游标按块前进，不是逐像素动画。没有增加触发、暂停或测距算法。双缓冲仍整帧重绘，覆盖是样点的显示组织方式，不是停止 LCD 刷新。
