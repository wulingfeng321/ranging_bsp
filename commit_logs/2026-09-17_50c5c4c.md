## 整理后的提交说明

在原有本地双麦克风波形基础上增加声学测距仪表界面，提供距离/测量状态发布接口，并改进工程路径及 CubeMX 再生成保护。

### UI 与音频状态

- 顶部 y=0..95 增加 ACOUSTIC RANGING 标题、BOARD DISTANCE、结果状态与麦克风状态。
- 两个波形区域移至 y=96..183、184..271，分别标注 LOCAL MIC L/R；纵向最大幅度从 48 像素调整为 28 像素。
- 保留 16 kHz、16-bit 双通道、160 ms 窗口、20 ms/div、共同自动缩放和显示双缓冲。
- 等待样点、麦克风初始化/启动失败、采集错误时仍刷新仪表区域，而不是直接退出所有显示处理。
- 未发布有效距离时显示 --.--- m；有效时按米显示三位小数。显示分辨率不代表测距精度。

### 新增接口契约

声明位于 `Core/Inc/app_mic_scope.h`，实现位于 `Core/Src/app_mic_scope.c`。

| 接口/状态 | 行为 |
| --- | --- |
| MicScope_SetDistanceMm(uint32_t) | 接收板间距离，单位毫米；允许 0..999999，标记 VALID 并记录发布时刻 |
| 参数 >999999 | 转为 INVALID，不显示为有效数值 |
| MicScope_SetRangeState(state) | 可设置 WAITING、MEASURING；其他输入转为 INVALID |
| VALID | 必须通过 SetDistanceMm 发布，不能由 SetRangeState 直接设置 |
| 有效期 | 发布后小于 5000 ms 有效；到期显示 RESULT EXPIRED 与占位符 |
| 调用场景 | Init 后在主循环调用，禁止直接从 DMA/网络 ISR 调用 |

到期逻辑影响显示有效性，内部枚举并没有自动改写为 INVALID。仅有新测量时刷新结果，不能每轮主循环反复提交旧值来延长有效期。

### 工程与初始化

- `main.c` 恢复生成区的 MX_LTDC_Init/MX_FMC_Init 调用，同时在对应函数 USER CODE 区使用条件编译禁用其生成实现，让 BSP 继续负责初始化。
- 对测试分支中保留的初始化函数增加显式引用，消除未引用警告；表达式不会启动这些外设。
- MSP 对未使用的 LTDC GPIO 局部变量增加显式引用。
- IAR 的四项 BSP/Fonts 头文件路径从 E 盘绝对路径改为基于 PROJ_DIR 的相对路径；仍依赖仓库上层的 BSP/Fonts。
- CubeMX 配置取消 X-CUBE-TOUCHGFX 第三方包记录，启用生成前备份、关闭删除旧文件，并调整 USB 初始化函数列表。

## 已实现与尚未实现

已实现的是 UI、状态管理、结果格式化和过期显示。没有新增 Ethernet 同步协议、统一采样时间戳、到达时间估计或距离计算；`SetDistanceMm` 只是接收未来算法算出的板间距离。当前没有业务调用向接口发布真实测距结果。
