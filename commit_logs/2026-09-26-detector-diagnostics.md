# 1.5 m 漏检：检测阶段诊断与测试方案

## 本次修改

- 移除 RMS 显示及 DMA 中的 RMS 计算，移除 DSP/MAX/BK 和 FS/TS/WIN/LCD 显示。
  内部原有 DSP 负载、积压统计仍可调试查看。
- 保留同步、丢样、事件收发、联合选峰和距离显示；整帧更新仍为 500 ms。
- 新诊断来自每块板自己的 L 通道 LEGACY 检测器，与屏幕所在的 L/R 区域无关。
- 复用原本已计算的相关值，不额外执行模板相关、不修改检测门限、搜索顺序和测距算法。
  间隙诊断会读取两个间隙的能量，包括原逻辑可能提前拒绝而不读第二个间隙的情况。
- 48 kHz、LEGACY/JOINT2、100～2000 mm 统计有效范围保持不变。

## 新字段

| 字段 | 含义 | 如何解释 |
|---|---|---|
| CG | 通过粗匹配、进入精搜索的次数 | 累计搜索种子数，不是检测到的签名数 |
| F1 | 精搜索区域没有第一段达标位置 | 第一段是上扫频 |
| F2 | 第一段有达标位置，但没有同一位置的第一、二段同时达标 | 第二段是下扫频 |
| F3 | 前两段能同时达标，但没有三段同时达标的位置 | 第三段是上扫频 |
| GP | 三段匹配通过后，被间隙能量检查拒绝的次数 | 可疑因素包括回波填充间隙、连续背景声、时序失配；不能单独证明回波 |
| OK | 完整签名检测通过次数 | 之后还需通过音频时间检查、候选提取和跨板配对；不是屏幕右上角 NET OK |
| NC | 本地候选提取没有可用三段峰的次数 | 解释 OK 已增加但 EVT 没有相应增加的情况；另查 AT-REJ |
| OV | 本地候选超过三个且存在评分接近的额外候选的次数 | 多峰歧义线索 |
| QMAX:a/b/c | 三段精匹配中各自已评估位置的最高质量，0～1000 | 当前 QTH=300；三项分别取最大，可能来自不同位置或不同签名，不能当作同一次成功匹配 |
| CMAX | 粗匹配最高质量，0～1000 | CTH 约 283；显示为平方根质量，内部粗门限仍为平方相关值 0.08 |
| GMIN | 所有通过三段检查的候选中，最小的“两个间隙较大能量 / 第一段能量”，百分数 | 尚无候选进入间隙检查时为 `--`；只表示最有利的一次，不代表整轮均通过 |
| GTH | 允许的最大间隙能量比 | 当前 100%，与之前算法一致 |
| QTH / CTH | 精匹配与粗匹配质量门限 | 显示存在取整，边界处应以通过/拒绝计数为准 |

新计数从开机累计，显示对 1,000,000 取模；极值也保留到重启。
对 LEGACY 而言，未发生计数回绕时：`CG = F1 + F2 + F3 + GP + OK`。
一段真实签名可以产生许多错位的搜索种子，所以正常近距离也会有不少 F1/F2/F3。
不要把这些计数除以 15 当成漏检率；用远近对照和各阶段占比判断。
后续段仅在前段通过时才计算，所以 QMAX 中 0 也可能表示该段没有获得评估机会。
新诊断不覆盖 WIDE 算法，WIDE 固件会显示提示。

原来的 AM/IC/DS 等联合状态会从 A 传给 B，不能把两屏相同的 AM 相加。

## 测试准备

1. 使用当前 48 kHz、10.5 s 内容 + 5 s 静默的音频，每轮仅播放一次，关闭循环。
2. 固定播放设备、音量、音效设置、扬声器朝向和高度；沿两板麦克风中心连线外侧播放。
3. 固定声源到近端麦克风的距离，例如 30 cm。改变两板距离时保持这项距离不变。
4. 距离以两板各自麦克风连线中点测量，记录实际值及室温。
5. 每轮先摆好设备，再重启两板；等两边 SYNC READY、AT:OK，保持安静约 5 s。
   开始播放前拍两板各一张，作为静默计数基线。
6. 完整播放并等待末尾 5 s 静默结束，立即拍两板各一张，记录是否出结果。
   拍照前不要移动或敲击设备，不要再播放一次；每轮重新启动清空极值和计数。

## 对照组（按顺序，每组先做 2 轮）

| 组别 | 两板距离 | 播放侧 | 遮挡 | 目的 |
|---|---|---|---|---|
| 1 | 30 cm | A | 两板声路无遮挡 | 获得正常检测时的阶段计数基线 |
| 2 | 150 cm | A | 两板声路无遮挡 | 重现远端 B 约检出 8 次的情况 |
| 3 | 150 cm | A | 恢复此前屏幕遮挡 A 的摆放 | 与组 2 对照遮挡影响，尽量只改变遮挡条件 |
| 4 | 150 cm | B | 两板声路无遮挡 | 检查漏检是否跟随远端，还是始终集中在同一块板 |

优先完成组 1、2；数据已能指向具体阶段时再做组 3、4。先保持音量一致，避免距离、遮挡、音量同时变化。

## 记录与判读

每轮记录：组别、轮次、实际距离、播放侧、音量、遮挡方式、温度；两板播放前后照片；
两板 EVT、CG/F1/F2/F3、GP/OK/NC/OV 的增量；QMAX/CMAX、GMIN；A 的 RX/AM/IC/PAIRED 和最终距离。

- 远端 CG 极少、CMAX 接近或低于 CTH：首先关注粗匹配能否进入精搜索。
- CG 足够但 F2/F3 相对正常组明显增加、OK 很少：重点检查相应段匹配及三段共同起点。
- GP 占 CG 的比例较正常组增加，OK 很少：重点检查间隙能量；若 GMIN 仍超过 100%，
  则本轮所有进入间隙检查的候选都未通过。GMIN 较低只说明至少有一次较好的间隙。
- OK 增加、NC 或 AT-REJ 增加，但 EVT 少：分别检查候选提取或音频时间有效性。
- 两板 EVT 均接近 15、B TX/ACK 与 A RX 相符，但 PAIRED 少且 AM/IC 增加：关注联合选峰。
- 若问题随远端位置交换，优先检查传播条件；若始终跟随同一块板，再检查该板硬件/摆放差异。

这批测试用于确定主要拒绝阶段，不凭单项最大值判断全部漏检原因，也不在同一轮同时改多个门限。

## 验证

- 实际 C 检测器测试：静默、第一段粗/精不一致、缺第二段、缺第三段、间隙高能量、
  完整签名通过、空候选，检查相应诊断及阶段计数总和。
- A/B 实际显示代码与 ST 字库预览：全部诊断固定可见，最大显示长度不越界。
- A/B 48 kHz 固件编译：零错误、零警告。
- 原有主机回归全部通过，包括 16/48 kHz 两板状态机、48 kHz 的 768 种 DMA/窗口对齐、
  200 组双方向亚采样延迟、反射/噪声拒绝、完整 15.5 s 音频及 WIDE 冒烟检查。
  相关乘加次数保持之前水平；新增诊断的实际硬件耗时未单独测量。
- IAR CSpyBat 已完成两板下载，启用下载校验并请求运行，两次退出码均为 0。
  A 的 ST-LINK 短号为 `67230834`，B 为 `87134138`。实际屏幕与声学效果待上述测试确认。
